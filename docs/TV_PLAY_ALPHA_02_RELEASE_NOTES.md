# 24Seven.FM TV — Alpha 02 closed-test release notes

## What's New

- A new, translucent first-use welcome screen lets listeners choose a starting
  station before audio begins. It defaults to 1980s.FM, shows the local station
  artwork, and keeps station selection silent until **Start listening**.
- The station selector now uses the individual station icons with clearer
  visual distinction between the station under D-pad focus and the station
  currently selected for listening. It fades away after a short idle period and returns
  when you use the D-pad.
- The idle visualizer collection now includes 24 distinct full-screen scenes,
  from Neon Kaleidoscope and Signal Deck to the DJ Soff Snep tribute deck,
  Chromafield, Psychedelic Scene, and Lava Lamp.
- Visualizer motion and rendering have been refined for more vivid audio response,
  smoother constrained-device performance, and Lava Lamp palette choices.

## Please test

- On a fresh app install, confirm the welcome screen fits fully on a 1080p TV,
  starts with 1980s.FM selected, and does not start audio while changing the
  pending station.
- Confirm **Start listening** begins the selected station. **Not now** dismisses
  the welcome screen without playback for the current session; after a full
  app restart, the welcome screen should appear again.
- Use the D-pad across each station icon and confirm focused, selected, and
  live states remain visually distinct.
- Browse the visualizer choices and report any clipping, distracting motion,
  or palette issue.

This alpha is for anonymous listening on Android TV. Please report playback,
remote-focus, accessibility, or visual issues without including personal data
or logs.
