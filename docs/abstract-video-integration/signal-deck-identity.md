# Signal Deck: distinct stereo broadcast console

Owner requirement: Signal Deck must be unique and different from Spectrum EQ and DJ Soff Snep. The previous 32-band spectrum duplicated the equalizer treatment. The new version retains its warm analog stereo RMS needles and replaces the entire spectrum display with a phase-correlation needle, a horizontal stereo-balance carriage, and PCM/STEREO/ATTACK lamps. No EQ bars, simulated frequency tuning, waveform scope or DJ stage choreography are drawn.

The instruments use existing decoded-PCM measurements. Balance is right-minus-left RMS dBFS, clamped to ±24 dB for pointer travel; saturated readouts explicitly show ≥24 dB. Correlation spans −1 to+1 only for stereo; mono is labeled and centered. Missing PCM hides the correlation/balance pointers and extinguishes the signal lamps. The attack lamp uses the existing measured transient envelope. Spectrum and ambient/stage animation fields have no effect on Signal pixels.

Four renderer/helper/test files changed, plus the picker display-description string. The shared audio drive, all other scene rendering, accepted Lantern/Laser treatments, Spectrum EQ, DJ Soff Snep, assets, playback and lifecycle remain unchanged. Native code only; no capture, permissions, dependencies, signing or publication changes. The owner dirty checkout is preserved.
